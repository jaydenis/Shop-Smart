# ShopSmart
THis project was an experiment in the use of AI to assist in the creation of a gamining supplement for the tabletop miniatures game [Forbidden Psalm](https://www.forbiddenpsalm.com/). 


This project was generated with:
- [Angular CLI](https://github.com/angular/angular-cli) version 18.1.1.
- [Lumo AI](https://lumo.proton.me)
- GitHub Copilot
- Google Gemin/Antigravity



## Development server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.


## Build

Run `ng build` to build the project. The build artifacts will be stored in the `dist/` directory.


## AI Prompts

I started with **Lumo**:
>"I'm starting a new game that is based on the official rules from Forbidden Psalm"

And fed it the quick start rules so thatit understood the basic game rules.

I added a some context:
>"This supplement is going to be like a "Scooby Doo and the gang vs The Evil Dead" slapstick horror comedy skirmish game that will make you die laughing"

From there it started generating an outline with some placeholders that I would fill with a rather funny dialog between myself and Lumo.

I spent about 12 hours total revising, adding, removing and sparing with Lumo until felt is was ready for play testing.

I copied the final draft (v1.2) which when pasted into a text editor and gave it a quick scan.

For fun I let Microsoft Copilt 365 Desktop App have a look at it. It's response was positive had a few suggestions. I told it to proceed and the 365 froze for a while and then started launching login prompts that inturn would flakeout and launch a new login prompt. I let it rest for a few days but it still doesn't work. 

I also let [Antigravity](https://antigravity.google/) have a go at it. It gave me similar feedback as 365  which I proceeded with but it burnt through my tokens pretty quickly.  

I moved on to GitHub Copilot which suprisingly pointed out some mistakes that Lumo, 365 and Antigratity missed. GHCP also gave me some pretty good suggestions on weapon balance, character synergy and a few other items that I folded into the document. 

Once I was happy with the GHCP session I dumped the text into a new draft (v1.3) and went back to Lumo. After parsing the text and reviewing the new changes it said someting along the lines of "GitHub CoPilot has made some good suggestions. I'll make a note of that." How did it know??
