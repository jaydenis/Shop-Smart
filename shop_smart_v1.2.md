## **SECTION 1: CLUE PROGRESSION**

Clues are scenario tokens representing evidence the crew collects. A Scenario states where its clues are found, how they are collected, and any special effects that use them. Clues are not spent unless that Scenario explicitly says so.

| Step | Mechanic |
| --- | --- |
| **Collect** | Crew gathers clues using the Scenario's clue rules |
| **Threshold** | Scenarios list a Clue Threshold (default **5**) |
| **Unlock** | Once the threshold is reached, the Scenario's win condition becomes available |

**Evidence Retention Rule:** Clues that have been spent (accusations, trap checks, decoding, etc.) still count toward any Clue Threshold or finale roll. Evidence doesn't disappear just because you used it.

## **SECTION 4: OMEN DECK EXPANSION**

### **Existing Omens (Quick Start Rules)**
| Omen | Effect |
| --- | --- |
| Bring it Down | Deal maximum damage with an attack |
| Lucky | Reroll any dice, yours or someone else's |
| Medic | Remove a Downed model from play, auto-pass death save |
| Close one | Cancel one Critical or Fumble |
| Resourceful | Reroll on loot table |
| Training | Automatically pass one test (jumping, morale, or combat) |

### **New Comedy Omens**
| Omen | Effect |
| --- | --- |
| **Plot Twist** | Switch initiative order — opponent activates last this round |
| **Slippery Floor** | Next hostile movement test auto-fails (trip) |
| **Running Gag** | Repeat same attack against enemy twice |
| **Red Herring** | Hide one clue/item from hostiles until end of scenario |
| **MacGuffin Drop** | Immediately find one key item within 6" of your position |
| **Fourth Wall Break** | Reroll any two tests this round |
| **Slapstick Timing** | Force one enemy to take their turn before all crew this round |
| **Plot Armor** | Auto-pass any single test this round |

**Rule:** Each Omen can only be used once per Scenario.
